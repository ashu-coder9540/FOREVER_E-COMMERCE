# Forever Ecommerce Frontend

A React + Vite ecommerce storefront for the Forever Ecommerce site.  
Built with React, Tailwind CSS, React Router, and a lightweight Vite setup.

## Features

- Home, Collection, Product, Cart, Orders, Place Order, About, Contact, and Login pages
- Search bar for collection filtering
- Cart management with totals
- Responsive mobile and desktop layout
- Reusable components for product items, hero sections, footer, and newsletter
- Fast development with Vite and hot module reloading

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- React Router DOM
- React Toastify
- ESLint
